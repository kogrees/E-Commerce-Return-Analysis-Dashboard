> **A business intelligence dashboard designed to uncover return trends, identify revenue loss, and help e-commerce businesses reduce product returns through data-driven insights.**

---

# 📖 Overview

Returns are one of the largest hidden costs in e-commerce. While increasing sales is important, understanding **why customers return products** is equally critical for improving profitability.

This interactive **Power BI dashboard** analyzes over **100,000 orders** to discover return patterns across product categories, customer segments, payment methods, shipping types, and regions. It helps stakeholders quickly identify operational issues and make informed business decisions.

---

# 🎯 Objectives

- Analyze return trends over time
- Identify the biggest causes of returns
- Measure financial impact caused by returns
- Compare return rates across categories
- Understand customer return behavior
- Discover regional return patterns
- Provide actionable business recommendations

# 💡 Key Business Insights

### 🏆 Product Category

- Sports products recorded the highest return rate.
- Football products showed the largest percentage of returns among all subcategories.

---

### 📉 Monthly Performance

- March 2023 recorded the lowest overall return rate.
- Product defects remained the leading reason behind returns.

---

### 👥 Customer Behavior

- New customers return products significantly more often.
- Loyal customers consistently demonstrate lower return rates.

---

### 💳 Payment Trends

Customers using Debit Cards exhibited the lowest return rate among all payment methods.

---

### 💰 Financial Impact

Returns resulted in an estimated **$554M revenue impact**, emphasizing the importance of improving product quality and customer experience.
